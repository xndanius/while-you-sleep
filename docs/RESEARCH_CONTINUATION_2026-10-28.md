# Bounded research continuation

The content loop can now retain one unresolved candidate and prioritize its
missing, already-approved implementation references in a later ordinary run.
This is acquisition continuity, not permission to raise scores or publish.

Before acquisition, a trusted step derives an intent from an intact completed
no-post bundle. It retains the exact prior proposed plan, limitations, source
packet and original hashes. The separate intent artifact is uploaded before the
scan starts. Creating or uploading this intent is not an attempted request.

The normal scan and source selector remain authoritative. A priority must match
the current sealed discovery item, its original registry attribution and the
existing cooldown. The ordinary primary fetch then must reproduce the material
text, native post identity, normalization version, complete-body hash and selected
span fingerprint. Changed evidence disables old-plan reference priority. No old
quote is silently applied to a different chore.

Within the existing ten-lead, three-per-feed and two-reference limits, matching
fixed documentation is prioritized for that one eligible candidate. No new
catalog URL, provider, credential, model invocation or manual dispatch is added.
Every started primary/reference operation is recorded before the call, and its
terminal status, request count and source hash are recorded afterward. Missing
terminal data is unknown/interrupted; failed calls remain failures. A partial
budget-limited attempt is not complete acquisition. Any begun or uncertain attempt
parks that exact gap instead of blindly repeating it. A planned but ineligible
intent does not consume an attempt. Unattempted dossiers survive the 24-hour
writer-history view through their immutable intent records.

The result is sealed before model access and imported through a separate bounded
artifact path using the trusted job-output hash, producer, run/attempt/head,
original dossier and current scan/selection fingerprints. Model-owned artifact
imports cannot write these directories. If an entire job dies before its result
can be archived, the preserved intent remains unknown; no successful request is
invented. Current scan/selection artifacts can be sealed from their files even
when the enrichment process failed before returning its normal outputs.

After completed acquisition the writer also receives the earlier proposed plan
and unresolved questions, without its earlier scores. New factual claims and all
ratings must use the current sources and pass the unchanged independent checker.
The existing final publication gate and 6/10 threshold remain authoritative.

Tests cover immutable plan preservation, changed source/body, cooldown, published
identities, forged provenance, reference budgets, failed and interrupted calls,
missing terminal receipts, importer isolation, and survival outside the short
writer-history window. Synthetic HTTP fixtures establish code behavior only;

automatic-cycle verification must separately establish whether acquisition,
writer use, fresh independent evidence and the final result occurred.
